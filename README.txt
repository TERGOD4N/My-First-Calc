# Калькулятор

Простой калькулятор на C++ и Qt Widgets.

**Как запустить:**

1. Распакуйте архив целиком в отдельную папку.
2. Дважды нажмите на файл **`calc.exe`** — откроется калькулятор. Если Windows скрывает расширения, файл будет называться **`calc`**.

Устанавливать Qt Creator не нужно. Файлы `.dll` и служебные папки из архива оставьте рядом с `calc.exe` — они нужны для работы программы.
